Custom Maps used on multiplayer by various dedicated COJ: BiB servers - mainly Dedicated[RR] and IranCOJ

These custom maps are quality maps, aimed for many different gamemodes. Some of them work well on WWL, some of them are best for shootout. It also contains the Old West Map Pack DLC and Multiplayer Campaign Map Pack from ModDB as well as some other maps whom I also posted on ModDB

Installation:

- Download the code, and put the MapsNet folder to Call of Juarez Bound in Blood / CoJ2 / Data folder. If you have MapsNet folder already, it will prompt you to swap it / paste some existing files. Just do that
- You are good to go.
